Results & analysis

What this is

An earlier research pipeline for post-treatment glioma segmentation carried nine named defects — a bilinear resize applied to label volumes, class imbalance left unhandled, checkpoints selected on a degenerate accuracy metric, an uncached loader that starves the GPU. This project reimplements it in PyTorch + MONAI as a controlled A/B:

  • Track A faithfully reproduces the defects — and fails in the documented way.
  • Track B fixes them, with the architecture frozen byte-for-byte.

The deliverable is not a leaderboard score — it is the A→B delta, which is immune to the project's deliberate handicaps because both tracks carry them equally.
